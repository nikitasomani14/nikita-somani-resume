# Nikita Somani — Professional Resume Website

A responsive, accessible portfolio and resume site built with semantic HTML, modern CSS, and lightweight vanilla JavaScript.

**Live site:** <https://nikitasomani14.github.io/nikita-somani-resume/>

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

The repository is designed for GitHub Pages with no build step. Publish the root of the `main` branch and keep `.nojekyll` in place.
